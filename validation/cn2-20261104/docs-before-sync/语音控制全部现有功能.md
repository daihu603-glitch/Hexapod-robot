# ESP32语音控制STM32现有功能（2026-11-03）

本版新增灯光、蜂鸣器、整机状态、ESP8266网络重启的语音接口。必须更新 ESP32 和 STM32 两端固件。STM32旧版UART4不认识rgb/beep命令，仅更新ESP32仍无法亮灯。

## 功能与说法

|功能|可以说|设备工具/参数|
|---|---|---|
|灯光开关|打开STM32的灯；关闭灯|self.stm32.set_led，color=white/off|
|灯光颜色|亮红灯/绿灯/蓝灯/黄灯/青灯/紫灯/白灯|color=red/green/blue/yellow/cyan/magenta/white|
|蜂鸣器|蜂鸣器响200毫秒；关闭蜂鸣器|self.stm32.beep，duration_ms=200/0，范围0～1000|
|连接检查|检查STM32是否在线|self.stm32.get_state；query what=ping|
|测距|读取超声波距离|self.stm32.query，what=distance|
|整机状态|查询STM32灯、蜂鸣器和网络状态|query，what=system|
|舵机状态|查询舵机状态|query，what=status|
|舵机角度|把0号舵机转到95度|self.stm32.set_servo，id=0..17、angle=45..135|
|舵机断电控制|关闭0号舵机PWM；关闭全部舵机PWM|self.stm32.disable_servo，id=0/-1；不是切断UBEC电源|
|步态状态|查询步态状态|self.stm32.gait，action=status|
|站立|让机器人站立|gait，action=stand|
|停止步态|停止行走|gait，action=stop；保持最后PWM，不自动落腿|
|前后左右移动、转向|三角步态向前移动一次，速度10%，不横移不转向|self.stm32.walk，mode=tripod，forward=10，left=0，yaw=0|
|其他步态|使用波纹步态/波浪步态|walk，mode=ripple/wave|
|网络重启|重启STM32的ESP8266热点和MQTT网络|self.stm32.restart_network；不是重启STM32主控|

walk三个百分比参数范围均为-100～100，负forward后退、正left左移、负left右移；yaw正负方向仍以现有机械配置和实物为准。现有1000ms行走租约保持原样，此工具单次发送，不提供持续行走，不自动续租。未校准仍由原STM32步态拒绝。

语音需要ESP32联网并与支持设备侧MCP的小智服务建立连接。自然语言由云端选择工具；固件不会新增当前STM32没有的功能（例如自动避障、自平衡、姿态反馈）。

## 回包与判定

所有动作提交后返回queued request_id，必须用get_state(request_id=编号)查询最终OK/ERR。queued/WAIT不是执行成功，timeout表示执行状态未知，不应自动重试动作。舵机/步态OK不证明实物动作已经完成。

system状态包含app、clients、rgb、beep、uptime、commands。app: 0=失败、1=复位、2=等待启动、3=配置、4=网络就绪、5=重试；rgb位掩码0关、1红、2绿、3黄、4蓝、5紫、6青、7白。网络重启返回started只表示已开始，完成后应再查system的app=4。

## 固件与烧录

firmware/ESP32-app.bin 与 firmware/STM32-verified.hex 为本版配套固件。STM32用ST-Link/Keil下载新的hex；如果使用Keil工程，先对STM32/Guide_MQTT/MDK-ARM/Guide_MQTT.uvprojx执行Build再Download，不要下载旧构建缓存。

ESP32在已激活ESP-IDF终端执行：

```powershell
cd 'C:\esp-projects\gec-r4-rotate'
idf.py -p COM15 -b 460800 app-flash
```

COM15须与实际串口一致。只更新应用，保留资源和配置。源代码仍在本目录ESP32与STM32子目录；Build-ESP32.ps1可将本目录源码同步到短路径重新编译。

接线仍为GPIO47(TX)→PC11(RX)、GPIO48(RX)←PC10(TX)、GND共地，115200/8N1。不插TF卡，两板分别供电。

## 变更范围和验证

STM32仅修改app_mqtt.c/.h和app_esp_link.c以开放既有功能，并扩展两个主机测试。步态、舵机、校准配置、RTOS调度、硬件驱动、原MQTT处理函数均保留；校验结果见validation/voice-all-20261103。

ESP32新增set_led、beep、restart_network，扩展query(system)。摄像头小横屏、方向、中文按钮保持原版。此前2026-11-02“STM32完全未改”的记录只对应当时的整合；本版增加上述串口入口。

两端编译与主机测试通过后交付；尚未实机烧录、验证语音选工具及硬件动作。先以“打开STM32红灯→查询状态→关闭灯”验证完整链路。
